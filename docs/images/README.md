# Battery behavior screenshots

Place runtime screenshots for the behavior guide in this directory.

| Suggested file | Capture |
| --- | --- |
| `charging-dual-battery.png` | Connected; BAT0 and BAT1 visible |
| `on-battery-dual-battery.png` | Removed; session fields populated |
| `charge-threshold.png` | One battery held by a threshold |
| `unknown-session.png` | Duration unknown after a gap |

Before adding an image:

- Crop it to the widget.
- Remove hostnames, serial numbers, notifications, and personal data.
- Use PNG format.
- Add descriptive alternative text when linking it from the behavior guide.
